# چک‌لیست Play (Unity)

1. پروژه 2D + کپی `Assets/Scripts`
2. Empty → Bootstrap → Play
3. شروع بازی → آموزش ۵ مرحله
4. نقشه: کلیک روی دژ / چوب / مزرعه
5. نوار پایین: ساخت، قهرمان، دفاع، مأموریت، اتحاد(=فروشگاه)
6. دفاع → شروع موج → یونیت‌ها + اعداد آسیب
7. فروشگاه → خرید تست → کریستال زیاد می‌شود
8. بستن و باز کردن → ذخیره حفظ شده

# مسیر رسیدن به ۱۰/۱۰ — دژ خاکستر (Ashen Citadel)

هدف: بازی استراتژی موبایل در سطح محصولات برتر بازار.

## واقعیت
۱۰/۱۰ = هنر حرفه‌ای + محتوا عمیق + پولیش موبایل + LiveOps + انتشار و داده.
کد فعلی ≈ پروتوتایپ قوی (حدود ۴/۱۰ محصولی).

## فاز A — Vertical Slice قابل‌فروش (۶٫۵–۷/۱۰) | ۴–۸ هفته
- اسپریت ساختمان و قهرمان با کیفیت استور
- VFX دفاع، موسیقی و SFX واقعی
- بالانس ۲۰ موج، APK روی گوشی واقعی
- آموزش ۲ دقیقه‌ای

## فاز B — Soft Launch (۸/۱۰) | ۲–۴ ماه
- محتوای بیشتر، IAP واقعی، اتحاد پایه
- Firebase analytics، نوتیفیکیشن
- Soft launch ۱–۲ کشور

## فاز C — Global (۹–۱۰/۱۰) | ۶–۱۲ ماه+
- فصل/رویداد، رتبه‌بندی، cloud save
- بومی‌سازی، LiveOps، ASO و جذب کاربر
- KPI: D1>40%, D7>15%

## بودجه حداقلی تقریبی
هنر ۲–۸k USD | صدا ۳۰۰–۱۵۰۰ | برنامه‌نویسی چند ماه full-time | بازاریابی جدا

بدون هنر و محتوا، فقط با کد به ۱۰ نمی‌رسیم.

ریپوی فعلی = پایه فاز A است.
